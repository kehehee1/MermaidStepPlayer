# 总体设计架构

本文档说明 Mermaid 流程图逐步播放器的整体架构、核心算法与交互模型。所有图示均为 Mermaid，可直接在本播放器中渲染查看。

## 1. 整体架构

用户输入的流程图代码，经解析得到 AST，再拆解为“分支”与“步骤”，最终在每次渲染时通过 Mermaid class / 边 class 做高亮着色。

```mermaid
flowchart TD
    U[用户: 粘贴 flowchart/graph 代码] --> D{图类型?}
    D -->|非流程图| NF[直接 render 完整图<br/>不支持逐步揭示]
    D -->|flowchart| P[parseFlowchart<br/>mermaid-ast]
    P --> AST[(AST: nodes / links / subgraphs)]
    AST --> FB[findBranches<br/>源→汇极大简单路径]
    AST --> BS[buildSteps<br/>深度优先逐步揭示]
    FB --> BB[buildBranch<br/>单分支逐步演示]
    BS --> STEPS[(步骤序列 STEPS)]
    BB --> BSTEP[(分支步骤序列)]
    STEPS --> R[renderStep<br/>mermaid.render + 着色指令]
    BSTEP --> R
    R --> SVG[SVG 画板: 分支绿 / 回边橙虚线 / 当前节点脉冲]
    SVG --> I[交互: 上一步/下一步/自动播放/分支切换/键盘]
    I --> R
```

## 2. 核心：分支提取算法 `findBranches`

**定义**：分支 = 图中所有“极大简单路径（源→汇）”。每条路径的诱导子图天然是单条简单路径：恰好 1 个头节点（入度 0）、1 个叶子节点（出度 0），其余均为中间节点。

**关键难点**：流程图可能含回边（环）。若不加保护，DFS 会沿 `A → … → A` 无限递归。算法用 **on-path 集合**在 DFS 下钻前判断目标是否已在当前路径上：

- 是 → 记为本回边（加入 `backEdges`），标记 `cyclic=true`，**不再下钻**（防死循环）；
- 否 → 正常递归。

分支名由路径上各边标签拼接而成；无标签时回退到目标节点 id；同名分支自动追加 ` #2` `#3` 去重。

```mermaid
flowchart TD
    S[开始: 对所有入度=0 的源] --> L[取一条出边 u→v]
    L --> C{onPath 含 v?}
    C -->|是| B[记回边: 记入 backEdges u→v<br/>cyclic=true, 不下钻]
    C -->|否| A[onPath.add v; 入栈 v]
    A --> SI{v 是汇? 出度=0}
    SI -->|是| ADD[生成分支: labelOf path<br/>seen 去重]
    SI -->|否| L
    ADD --> POP[出栈 v, onPath.delete v]
    B --> POP
    POP --> MORE{还有出边?}
    MORE -->|是| L
    MORE -->|否| NEXT{还有源?}
    NEXT -->|是| S
    NEXT -->|否| DEDUP[名称去重: 同名加 #2 #3]
    DEDUP --> RET[返回 branches / cyclic / backEdges]
```

## 3. 播放与模式切换（状态模型）

`show(i)` 以 `i===-1` 表示“总览/分支预览”，`i>=0` 表示逐步演示中的第 `i` 步。`branchMode` 与 `branchPreview` 控制是否处于单分支演示。

```mermaid
stateDiagram-v2
    [*] --> 总览: 生成步骤 show -1
    总览 --> 全局逐步: 下一步/→
    全局逐步 --> 全局逐步: 上一步/下一步/自动播放
    全局逐步 --> 总览: 重置 或 上一步到头
    总览 --> 分支预览: 选某分支 show -1
    分支预览 --> 分支逐步: 下一步/→
    分支逐步 --> 分支逐步: 上一步/下一步/自动播放
    分支逐步 --> 分支预览: 上一步到头
    分支预览 --> 总览: 选全部 或 重置
    全局逐步 --> 分支预览: 直接选分支 状态重置
```

> 注意：点击“生成步骤”会重置 `branchMode` / `branchPreview`，避免上一图的分支预览残留导致画板不刷新。

## 4. 着色与样式

渲染时对 SVG 施加三类 class，互不冲突：

| 样式 | 含义 | 触发 |
|------|------|------|
| `.branchNode` / `.branch-edge` + `.edge-flow` | 当前分支路径（绿 + 流动虚线） | 在 `branchNodes` / `branchEdges` 中 |
| `.cycle-edge` | 回边 / 循环（橙色虚线） | 在 `backEdges` 且两端均已揭示 |
| `.dimNode` / `.dim-edge` | 其它已揭示节点/边（淡灰） | 已揭示但不在当前分支 |
| `.curNode` | 当前节点（橙色脉冲光晕） | `currentId`（预览态不加） |

回边**只做视觉标记、绝不沿其遍历**，因此既能提示“否会回流”，又不会触发无限循环。

## 5. 模块依赖与测试

- 解析：`mermaid-ast`（`parseFlowchart` / `renderFlowchart` / `detectDiagramType` / `parse` / `render`）。
- 渲染：`mermaid@10` 的 `mermaid.render`。
- 算法自测：`branch_test.mjs`（Node 运行），覆盖无标签易重名、带标签复杂图、三路并行、含回边环、平行同标签去重、多源+合并+回边大图，并断言分支数、1 头 1 叶、名称唯一、回边检测。

```mermaid
flowchart LR
    HTML[mermaid-step-player.html] -->|镜像算法| TEST[branch_test.mjs]
    TEST -->|node 跑通| OK[防护回归: 环/去重/回边]
    HTML -->|浏览器打开| RUN[逐步播放 + 分支演示]
```
